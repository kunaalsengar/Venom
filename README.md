# VENOM

An interactive cinematic symbiote transformation experience.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Canvas 2D
- ES Modules

## Run Locally

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://localhost:8765/
